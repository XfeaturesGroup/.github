# Coordinated disclosure

This organisation supports responsible, coordinated disclosure of security
issues. A report is handled privately until affected users can be protected and
a fix or mitigation is available.

Public disclosure should describe the impact, affected versions, fixed versions
and practical mitigation. It should not include unnecessary exploit automation,
customer data or credentials. Reporters should coordinate timing with the
maintainers through the process in [SECURITY.md](SECURITY.md).
