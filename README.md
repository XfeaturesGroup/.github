# XfeaturesGroup community files

This repository supplies the default community-health files for public
repositories in the XfeaturesGroup organisation. Individual repositories can
override any of these files when their maintenance or disclosure requirements
differ.

```
profile/README.md         organisation profile shown on GitHub
SECURITY.md               coordinated vulnerability disclosure policy
SUPPORT.md                support and contact guidance
CONTRIBUTING.md           contribution and review expectations
CODE_OF_CONDUCT.md        community conduct standard
GOVERNANCE.md             maintenance and decision-making model
PULL_REQUEST_TEMPLATE.md  default pull-request checklist
ISSUE_TEMPLATE/           structured bug and feature forms
```

The files in this repository intentionally describe processes rather than
product-specific promises. Service documentation, operational status and
release notes belong to their respective repositories.
